Informática para Internet

Contexto Geral

O curso de Informática para Internet (conhecido também como Infonet), é a área que se trabalha com o desenvolvimento de páginas web. Durante o curso os alunos aprenderão a utilizar softwares para edições de imagens, controlar/editar dados, solucionar problemas, realizar o design e tornar o site acessível.

Atualmente o vestibular para este curso não está mais disponível na instituição Etec Lauro Gomes.

O que aprendemos?

  • Desenvolvimentos de Páginas Web;
  • Costumização de plataformas e desenvolvimento de identidades visuais;
  • Manutenção e criação de Banco de Dados;
  • Desenvolvimento de planilhas e controle de dados;
  • Otimização de imagens.
